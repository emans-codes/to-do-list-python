# 📝 To-Do List — Python

A simple **command-line To-Do List application** built with Python.

## ✨ Features

* ➕ Add tasks
* 👀 View tasks
* 🗑️ Delete tasks
* 🚪 Exit the program
* ⚠️ Handles invalid task numbers and non-numeric input

## 🐍 Python Concepts Practiced

* Lists
* `while` loops
* `if / elif / else` statements
* `enumerate()`
* `try / except`
* User input
* `break` and `continue`

## ▶️ How to Run

Make sure Python is installed, then run:

```bash
python todo_list.py
```

Follow the options shown in the terminal to manage your tasks.
